## 目前結論

1. 產品定位：開源的台灣繁中注音輸入法，讓使用者真的用得開心。不是泛中文輸入法，也不是寫作助理。
2. 第一價值：降低連續注音輸入時的選字修正成本；重開之後還記得。
3. 速度原則：每次按鍵同步路徑不可等待小型語言模型；模型只能在背景、停頓後、送出前、或離線訓練路徑使用。
4. 隱私原則：預設不連網、不上傳輸入內容、不記錄原文輸入。
5. 2026-08-17 轉向：自適應先指使用者詞、選字覆寫記憶、線上詞彙生長；公開語料 n-gram 是第二層；SLM 只當離線教師。見 [台灣繁中注音輸入法_2026_08_方向重評.md](台灣繁中注音輸入法_2026_08_方向重評.md)。
6. 本機個人化：使用者詞已落盤。`UserOverrideModel` 已可寫到 `user-override-model.txt`。2026-08-18 改鍵臂：K1 有輸入中途有害（`在`→`再`），不推；K2 轉移 2/8 且 prefix 有害 0，但不做默默回頭改字。Tokunaga 2011：個人化可能讓轉換變差。
7. 授權結論：修改小麥注音本體大致可行。HuoziIME 為 GPL-3.0，不可併入。librime-octagram 為 BSD-3-Clause（LICENSE 已核），仍不複製其原始碼；GPL 不相容來自 Squirrel / Weasel / ibus-rime / rime-ice。
8. Phase 0/1 與 Phase 2 反證仍成立：規則 scorer 在為它準備的句子上有效；prompt-only SLM 與 count ranker 不能 promotion。
9. `heldout_generalization_clean` 63/63 是規則擴充加讀音 hygiene 後的回歸門檻，不再當作泛化證據。
10. Ubuntu 優先使用官方 fcitx5-mcbopomofo，不把自做第三個 addon 當 P0。
