# Phase 3：macOS 實驗整合開發步驟

最後更新：2026-06-18

## 目標

把已通過評測的重新排序器整合到 macOS 小麥注音 fork，以實驗設定提供使用者試用。重點是可關閉、可回退、不中斷打字、不記錄原文。

## 讀檔順序

1. `docs/台灣繁中注音輸入法_Phase1_輕量重新排序開發步驟.md`
2. `docs/台灣繁中注音輸入法_Phase2_SLM實驗開發步驟.md`
3. `docs/台灣繁中注音輸入法_速度需求.md`
4. `docs/台灣繁中注音輸入法_法律授權盤點.md`
5. `Source/InputState.swift`
6. `Source/KeyHandler.mm`
7. `Source/LanguageModelManager.mm`

## 開發步驟

1. 新增實驗設定。
   - 預設關閉。
   - 可切換 baseline、P1、P2。
   - 設定變更不需要重裝。
2. 整合 scorer。
   - P1 可在同步路徑使用，但需符合 p95 小於 2 ms。
   - P2 只能在暫停或送出前路徑使用。
   - 過期模型結果必須丟棄。
3. 實作回退。
   - scorer 停用。
   - scorer 逾時。
   - 模型檔不存在。
   - 模型載入失敗。
   - scorer 回傳格式錯誤。
4. 加入非內容型觀測。
   - 是否啟用。
   - 耗時區間。
   - 回退次數。
   - 錯誤碼。
5. 建立實際使用檢查表。
   - 長句連續輸入。
   - 英文混輸。
   - 使用者詞。
   - 排除詞。
   - 快速連打。
   - 切換輸入法。
6. 建立錯誤回報格式。
   - 使用合成案例重現。
   - 不要求使用者提供私人原文。

## 驗收條件

1. 使用者可在設定中啟用、停用、切換 scorer。
2. 停用後行為與原本小麥注音一致。
3. 模型缺失、逾時、錯誤時文字不遺失。
4. 快速連續打字不等待小型語言模型。
5. 紀錄中沒有原始注音、候選文字、送出文字、使用者詞庫內容。
6. 實際使用檢查表完成，且問題皆有分類。

## 停止或轉向條件

- 若使用者因延遲停用，先回到速度模型，不擴大發佈。
- 若候選行為讓使用者難以預期，先改善 P1 或模型任務，不發 alpha。
- 若任何紀錄含原文，立即停止發佈並修正紀錄邊界。

## 禁止事項

- 不預設開啟模型。
- 不在每次按鍵同步等待模型。
- 不用使用者私人輸入當錯誤回報必填內容。
- 不讓模型結果覆寫已送出的文字。
