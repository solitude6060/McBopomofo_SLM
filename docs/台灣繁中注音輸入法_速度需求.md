# 台灣繁中注音輸入法速度需求

最後更新：2026-06-18T18:23:04+08:00

## 核心原則

輸入法是即時互動系統。使用者每按一個鍵，畫面上的組字、候選字、游標與送出行為都必須立即回應。任何會造成可感知停頓的模型推論，都不能放在每次按鍵的同步路徑上。

本專案的速度原則：

1. 按鍵同步路徑只允許現有詞庫查詢、讀音網格更新、輕量分數調整。
2. 小型語言模型不可阻塞按鍵事件。
3. 模型推論必須可取消、可逾時、可回退。
4. 模型結果晚到時，不可改寫使用者已確認送出的文字。
5. 模型故障時，輸入法必須退回現有小麥注音行為。

## 本地程式依據

目前小麥注音核心路徑已有微秒級觀測點：

- `Source/Engine/gramambular2/reading_grid.h` 的 `WalkResult` 包含 `elapsedMicroseconds` 欄位，可作為基準延遲量測的起點。
- `Source/Engine/McBopomofoLM.cpp` 的 `getUnigrams()` 負責主詞庫、使用者詞彙、排除詞、詞彙替換、巨集與轉換後去重。這是同步路徑，不能被慢速模型取代。
- `ReadingGrid` 的候選字與覆寫機制已存在，模型應調整分數或提供候選排序建議，不應直接接管送字。

## 速度分層

| 路徑 | 允許工作 | 不允許工作 | 目標 |
|---|---|---|---|
| 每次按鍵同步路徑 | 注音解析、詞庫查詢、網格更新、輕量重新排序 | 小型語言模型推論、磁碟大量讀寫、網路請求 | 使用者無感 |
| 停頓後路徑 | 使用者短暫停頓後預先計算候選排序 | 改寫已送出的文字 | 可取消 |
| 送出前路徑 | Enter、空白、標點或明確提交前的短時間重新排序 | 超過逾時仍等待 | 逾時即回退 |
| 背景路徑 | 預載模型、建立快取、更新個人詞頻、排入 adapter 訓練佇列 | 影響按鍵處理 | 低優先權、可取消 |
| 離線路徑 | 自行訓練、資料清理、評測、adapter 訓練 | 在輸入過程同步執行 | 使用者明確啟動或閒置時觸發 |

## 初始延遲預算

這些數字是工程預算，不是最終使用者研究結果；第一階段必須用實測校正。

| 項目 | 目標 | 硬性上限 |
|---|---:|---:|
| 現有引擎單次 `walk()` | 建立基準，不增加 | 不得因新功能退化超過 10% |
| 按鍵同步輕量重新排序 | p95 小於 2 ms | p99 小於 5 ms |
| 候選視窗更新 | 不等待模型 | 不得出現可感知停頓 |
| 送出前小型語言模型重新排序 | p95 小於 20 ms | 超過 30 ms 直接回退 |
| 模型載入 | 背景載入 | 不得阻塞輸入法啟動與首次按鍵 |
| 本機訓練與 adapter 訓練 | 使用者明確啟動或閒置時觸發 | 不得在打字期間自動啟動 |

## 模型使用策略

### 不做

- 不在每次注音鍵輸入時同步呼叫小型語言模型。
- 不用模型直接產生送出的文字。
- 不讓模型晚到結果覆蓋使用者已選字。
- 不因模型未載入而讓輸入法不可用。

### 要做

- 每次按鍵先走現有小麥注音路徑。
- 輕量重新排序先處理常見歧義與英文混輸。
- 模型只在提交前、使用者停頓後、背景預取、或離線訓練中使用。
- 模型輸出限制在現有候選集合內，只能回傳排序或分數。
- 對每次模型使用記錄非內容型指標：是否逾時、耗時區間、是否回退、模型版本。
- adapter 訓練只能在背景低優先權或離線路徑執行，且必須可取消。

## 驗收指標

速度驗收必須和準確率一起看，不能只看模型分數。

最低驗收：

1. 關閉模型時，行為與現有小麥注音一致。
2. 開啟輕量重新排序時，現有引擎測試通過，按鍵同步路徑 p95 小於 2 ms。
3. 開啟小型語言模型時，模型逾時不影響輸入，且回退後文字不遺失。
4. 英文混輸句子中，英文片段不被錯誤轉換或移位。
5. 任何錯誤紀錄不得包含原始輸入內容、候選文字或送出文字。
6. adapter 重新訓練不得在使用者打字期間自動啟動；若已在訓練，按鍵活動應能暫停或取消訓練。

## 研究來源

- HUOZIIME 研究指出，本機大型語言模型輸入法的難點包含即時性、隱私與裝置端限制：https://arxiv.org/abs/2604.14159
- `lm-Meter` 研究指出，本機語言模型延遲需要細分到不同推論階段量測，不能只看模型大小或理論運算量：https://arxiv.org/abs/2510.06126
- `llama.cpp` 提供本機 C/C++ 推論、量化與 Apple Silicon 支援，但這不等於可以放入每次按鍵同步路徑：https://github.com/ggml-org/llama.cpp
