# 台灣繁中注音輸入法驗收總表

最後更新：2026-06-18

## 產品級驗收

| 項目 | 驗收方式 | 通過標準 |
|---|---|---|
| 台灣繁中定位 | 檢查產品需求與評測案例 | 台灣用語、注音、英文混輸為一級需求 |
| 非聊天助理 | 檢查候選輸出限制 | 模型不能自由產生送出文字 |
| 本機隱私 | 檢查程式與紀錄 | 預設不連網，不記錄原文 |
| 可回退 | 測試 scorer 停用、逾時、缺檔 | 行為回到小麥注音 baseline |
| 本機個人化 | 檢查設定、儲存、刪除、回退 | 預設關閉，明確開啟後才保存 L1 修正事件 |
| macOS 優先 | 檢查 Phase 3 | 實驗設定可啟用與停用 |
| Ubuntu 路線 | 檢查 Phase 4 | 評測核心可在 Ubuntu 執行 |

## 速度驗收

| 路徑 | 通過標準 | 失敗處置 |
|---|---:|---|
| baseline | 只量測不加負擔 | 作為後續比較基準 |
| P1 同步重新排序 | p95 小於 2 ms，p99 小於 5 ms | 降低特徵複雜度或改為非同步 |
| P2 送出前模型重新排序 | p95 小於 20 ms，超過 30 ms 回退 | 不導入 runtime |
| Adapter 訓練 | 不在打字同步路徑 | 背景低優先權、可取消 |
| 模型載入 | 不阻塞第一次按鍵 | 改背景載入或選用下載 |

## 正確率驗收

| 階段 | 指標 | 通過標準 |
|---|---|---|
| Phase 0 | 基準可重現 | 同機兩次報告一致 |
| Phase 1 | 歧義錯誤率 | 相對 baseline 下降至少 10% |
| Phase 1 | 英文混輸 | 不低於 baseline |
| Phase 2 | SLM 額外收益 | 相對 Phase 1 額外下降至少 5% |
| Phase 2 | 台灣繁中保留測試 | 不退化 |
| Phase 2 | 英文混輸保留測試 | 不退化 |

## 授權與法務驗收

| 項目 | 通過標準 |
|---|---|
| 小麥注音 fork | 保留 MIT License 與 copyright |
| 品牌識別 | fork 不讓使用者誤認為官方版本 |
| GPL 程式碼 | 不複製進 MIT 發佈路線 |
| LGPL 元件 | 若整合，保留替換與授權義務 |
| 模型權重 | 每個模型檔都有 license 記錄 |
| 訓練資料 | 每個來源都有 manifest |
| 私有資料 | 不進 commit、紀錄、發佈包 |
| 本機修正事件 | 只在使用者明確開啟後保存，且可刪除 |
| 個人 adapter | 不包進公開 release |

## 隱私驗收

| 項目 | 通過標準 |
|---|---|
| 網路 | 排序與評測 runtime 預設不發網路請求 |
| 紀錄 | 只允許計數器、耗時區間、錯誤碼、回退狀態 |
| 禁止紀錄 | 原始注音、候選文字、送出文字、使用者詞庫內容 |
| 自訓 | 使用者明確選檔，且可刪除 |
| 本機修正事件 | 預設關閉；啟用後只存本機，有保留期與數量上限 |
| 禁止收集 | 密碼欄位、安全輸入、剪貼簿、完整視窗標題、網址、完整檔案路徑 |
| 錯誤回報 | 使用合成案例，不要求私人原文 |

## 階段閘門

| 閘門 | 通過才可進入 | 不通過時 |
|---|---|---|
| Phase 0 完成 | Phase 1 | 補評測或先補詞庫 |
| Phase 1 達標 | Phase 2 或 Phase 3 P1 runtime | 若已足夠，延後模型 |
| Phase 2 達標 | Phase 3 P2 runtime | 不導入模型 runtime |
| Phase 2.5 隱私達標 | 自訓與 adapter 使用者測試 | 保留研究工具 |
| Adapter promotion gate | 啟用新 adapter | 保留報告但不啟用 |
| Phase 3 實際使用達標 | 公開 alpha | 縮小測試或回到排序器 |
| Phase 4 ADR 完成 | Linux 前端實作 | 暫停 Ubuntu 前端 |

## 完成定義

一個階段只有在以下條件全部成立時才算完成：

1. 對應開發步驟檔案的交付項目存在。
2. 對應報告存在，且包含指標與失敗案例。
3. 自動測試或手動檢查結果可重現。
4. 沒有違反速度、隱私、授權、回退邊界。
5. 下一階段是否繼續已有明確決策。
6. 若階段產生 adapter，必須有 manifest、評測報告、回退點與刪除方式。
