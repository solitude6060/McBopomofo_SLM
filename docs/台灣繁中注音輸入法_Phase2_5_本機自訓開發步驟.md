# Phase 2.5：本機自訓開發步驟

最後更新：2026-06-18

## 目標

提供使用者明確啟動、完全本機、可刪除、可回退的自訓或本機調適工具。這一階段涵蓋兩條路線：使用者選檔語料，以及本機修正事件累積後觸發 adapter 重新訓練。

## 讀檔順序

1. `docs/台灣繁中注音輸入法_Phase2_SLM實驗開發步驟.md`
2. `docs/reports/phase2_slm_experiment_report.md`
3. `docs/台灣繁中注音輸入法_法律授權盤點.md`
4. `docs/台灣繁中注音輸入法_需求收集.md`
5. `docs/台灣繁中注音輸入法_本機習慣收集與Adapter訓練.md`

## 開發步驟

1. 定義本機自訓輸入格式。
   - 使用者明確選檔。
   - 支援純文字。
   - 不自動掃描家目錄或剪貼簿。
2. 定義本機修正事件格式。
   - 使用者選了第幾候選。
   - 原第一候選與最後選中候選。
   - 有限長度注音與上下文。
   - 應用程式類別，不保存完整視窗標題。
   - 時間桶，不保存精確時間戳。
3. 建立資料清理流程。
   - 去除空行與明顯非中文內容。
   - 標記英文片段。
   - 無法判讀授權的外部貼文不應被納入可散布模型。
   - 修正事件需做長度截斷、封鎖清單過濾、保留期清理。
4. 建立本機訓練命令。
   - 可離線執行。
   - 產生模型 manifest。
   - 產生評測報告。
5. 建立 adapter 重新訓練觸發器。
   - 事件數達門檻。
   - 使用者手動觸發。
   - 使用者匯入本機語料。
   - 週期排程且事件數達最低門檻。
6. 建立 promotion gate。
   - 台灣繁中保留測試不退化。
   - 英文混輸保護不退化。
   - 最近修正事件回放有改善。
   - p95 延遲符合預算。
   - 舊 adapter 可回退。
7. 建立刪除與重設流程。
   - 刪除本機修正事件。
   - 刪除自訓資料快取。
   - 刪除自訓模型。
   - 刪除 adapter。
   - 還原預設 scorer。
8. 建立防誤打包檢查。
   - CI 或本機檢查不得把使用者私有資料、模型或中間檔包進 release。
9. 建立 UI 或命令列提示。
   - 說明資料留在本機。
   - 說明如何刪除。
   - 說明自訓模型不是預設品質保證。
   - 顯示事件數量、資料大小、最近訓練時間、adapter 狀態。

## 驗收條件

1. 使用者可在離線狀態下完成一次本機訓練或調適。
2. 使用者明確開啟本機個人化學習後，修正事件可累積到門檻並觸發 adapter 訓練。
3. 產生的模型或 adapter 可啟用、停用、刪除。
3. 模型缺失或格式錯誤時，輸入法回退到預設 scorer。
4. manifest 記錄來源、模型版本、資料範圍、評測結果。
5. adapter 未通過 promotion gate 時不啟用。
6. 本機私有資料不出現在紀錄、commit、發佈包。
7. 使用者可一鍵或單一命令刪除自訓產物、修正事件與 adapter。

## 停止或轉向條件

- 若 Phase 2 未證明模型價值，不做神經 adapter；可保留非模型的本機詞頻與覆寫統計。
- 若自訓結果容易過度擬合且評測退化，僅保留研究工具，不進入產品。
- 若隱私邊界無法自動驗證，不開放給一般使用者。

## 禁止事項

- 不自動上傳訓練資料。
- 不自動掃描使用者檔案。
- 不在預設狀態保存 L1 修正事件。
- 不收集密碼欄位、安全輸入、剪貼簿、完整視窗標題、網址、完整檔案路徑。
- 不把使用者本機資料包進 release。
- 不把自訓模型或 adapter 設成預設模型。
