# Training Plan: Taiwan Traditional Chinese Bopomofo Reranking

Last updated: 2026-06-18T18:20:30+08:00

## Objective

Create a reproducible training path for contextual Bopomofo candidate reranking
focused on Taiwan Traditional Chinese, Taiwan vocabulary, Bopomofo readings, and
English-mixed desktop writing.

Self-training is allowed, but no trained model should be promoted into runtime
use without beating deterministic baselines on held-out evaluation data.

## Training Target

The model task is candidate reranking:

Input:

- previous committed context;
- current Bopomofo reading sequence;
- candidate values generated by the existing engine;
- protected English spans;
- optional domain label.

Output:

- score delta or rank over existing candidates.

The model must not generate arbitrary committed text during the MVP.

## Data Sources

Candidate source categories:

- Public Taiwan Traditional Chinese text with compatible licenses.
- Project-authored synthetic sentences for ambiguous Bopomofo readings.
- Public Taiwan government/open-data terminology where license permits use.
- User-provided local text files for personal adaptation.
- Larger teacher-model generated examples only when the prompt inputs are public
  or synthetic and the resulting license constraints are acceptable.

Excluded by default:

- Simplified Chinese corpora.
- Pinyin input corpora.
- Private chat, email, documents, or clipboard text unless the user explicitly
  imports local files for training.
- Any source whose license does not allow the intended training or
  redistribution path.

## Taiwan Language Requirements

The data pipeline must preserve:

- Taiwan Traditional Chinese orthography.
- Taiwan word choices and local institutions.
- Bopomofo readings and tone marks.
- English product names, code identifiers, commands, package names, version
  strings, file paths, and acronyms.
- Common punctuation patterns in Taiwan writing.

The pipeline must flag:

- Simplified Chinese leakage.
- Regionally inappropriate vocabulary.
- automatic conversion errors.
- ambiguous readings with no reliable expected output.

## Pipeline

1. Source registration:
   - source name;
   - URL or local path;
   - license;
   - redistribution status;
   - domain;
   - Taiwan relevance;
   - collection timestamp.

2. Text normalization:
   - normalize Unicode;
   - keep Traditional Chinese;
   - reject or review Simplified Chinese conversions;
   - preserve ASCII and punctuation spans.

3. Bopomofo annotation:
   - use existing dictionary lookup when possible;
   - record missing readings;
   - avoid silently inventing readings.

4. Candidate generation:
   - run the current engine to collect candidate sets;
   - keep expected target and candidate rank;
   - discard cases where the expected target is absent unless the case is for
     dictionary expansion.

5. Split:
   - split by source document before sentence-level processing;
   - keep held-out Taiwan and English-mixed test sets untouched.

6. Train:
   - start with a lightweight reranker;
   - compare against deterministic contextual reranker;
   - only then test transformer SLM reranking.

7. Evaluate:
   - exact sentence accuracy;
   - token accuracy;
   - target candidate rank;
   - English span preservation;
   - p50 and p95 latency;
   - model size and memory footprint.

## Self-Training Mode

User-provided training must be local-only.

Requirements:

- The user selects local text files explicitly.
- Training data is stored under a user-controlled local directory.
- The app provides reset/delete for local adaptation artifacts.
- Local examples are not committed, logged, uploaded, or included in release
  packages.
- Runtime can disable or remove a self-trained model without reinstalling.

## Promotion Criteria

A trained model can move from experiment to runtime candidate only if:

- it beats the deterministic contextual reranker on held-out Taiwan fixtures;
- it does not regress English-mixed fixtures;
- p95 commit-time reranking latency is under the selected runtime budget;
- memory and package size are acceptable for desktop IME use;
- source manifests and licenses are complete;
- fallback behavior is tested.

## Initial Experiments

1. Deterministic baseline:
   - phrase transition counts;
   - protected English spans;
   - Taiwan lexicon boosts.

2. Small neural reranker:
   - character/Bopomofo embeddings;
   - candidate pairwise ranking loss;
   - no generative decoding.

3. Transformer SLM reranker:
   - candidate-constrained output;
   - quantized runtime;
   - commit-time scoring first.

4. Distillation:
   - use a larger model only to label public or synthetic examples;
   - train a compact local reranker for runtime.

## Open Decisions

- Select the first redistributable Taiwan text source.
- Define the minimum corpus size for a meaningful Phase 2 experiment.
- Choose whether the first trained model is a neural reranker or a quantized
  transformer SLM.
- Define the self-training storage path and deletion behavior for macOS and
  Ubuntu.
