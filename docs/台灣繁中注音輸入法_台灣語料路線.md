# 台灣語料路線

最後更新：2026-08-17

## 目標

建立台灣繁中注音輸入法的語料使用策略，明確區分：

1. 可放入公開 benchmark 的資料。
2. 可用於訓練或 adapter 調適的資料。
3. 只能做詞彙參考或本機私有實驗的資料。
4. 不建議使用的資料。

原則：輸入法任務不是通用聊天模型訓練。優先需要的是可轉注音、可重播、可量測候選排序的台灣繁中句子與詞彙。

## 來源矩陣

| 來源 | 授權 / 來源狀態 | 建議用途 | 不建議用途 | 判斷 |
|---|---|---|---|---|
| 教育部國語辭典公眾授權資料 | CC BY-ND 3.0 TW；教育部頁面寫明可重製、散布、傳輸，但不得修改 | 讀音、詞彙、歧義詞抽樣、手寫 benchmark 種子 | 直接改寫成訓練語料、散布修改後釋義 | 適合 benchmark 種子與讀音來源，不直接拿釋義訓練 |
| g0v `moedict-data` | 機器可用 JSON；底層辭典著作權仍屬教育部，格式重編部分 CC0 | 取得教育部辭典資料的工程入口 | 視為完全無限制語料 | 可用，但 manifest 必須標示教育部 CC BY-ND 與 g0v 格式轉換來源 |
| 政府資料開放平臺資料 | 政府資料開放授權條款第 1 版，與 CC BY 4.0 相容；需顯名 | 機關名、地名、法規名、行政詞彙、公開 benchmark、訓練候選 | 未檢查個資或第三方權利的資料 | 高優先，逐資料集確認欄位與授權 |
| 法規、政府公告、機關名冊 | 通常來自政府開放資料或官方網站，需逐項確認 | 台灣正式書面詞、政府機關名、法律詞彙、長詞切分 | 直接大量訓練未確認授權資料 | 適合作為詞彙與 benchmark；訓練需 manifest |
| TMMLU+ | Hugging Face 顯示 22,690 rows，論文定位為繁中基礎模型評測 | 台灣領域詞彙覆蓋檢查、模型常識側評，不作主要 IME benchmark | 直接當注音輸入法準確率指標 | 可做輔助 benchmark，不是候選排序核心資料 |
| DRCD | 繁中閱讀理解資料；論文寫 10,014 段、2,108 篇 Wikipedia、30,000+ 問題 | 泛繁中理解資料、長句切分壓力測試 | 當作台灣用語 benchmark 主體 | 繁中但台灣性不足，需區域詞過濾 |
| Taiwan.md | 網站標示 CC BY-SA 4.0，台灣知識庫，部分文章由 AI 輔助產生且社群審核 | 台灣文化、地名、人物、科技詞彙；可做署名且相容的公開 benchmark 候選 | 訓練會散布的模型或 adapter，除非先處理 BY-SA 義務 | 適合台灣詞彙發現；訓練用途需法律確認 |
| 國家文化記憶庫 | 文化部平台；各項素材可能有不同授權 | 只使用明確開放授權項目做台灣文化詞彙與 benchmark | 批次抓取未篩授權內容 | 需 item-level 授權過濾 |
| Common Voice zh-TW | Common Voice 資料集採 CC0；偏語音與句子 | 短句、口語句型、語音相關後續研究 | 作為主要桌面文字輸入 benchmark | 可低優先使用，需確認語言子集與品質 |
| TAIDE / Taiwan LLM / Breeze 論文 | 可作台灣模型與評測先例；訓練資料本身未必可直接取得或再散布 | 研究參考、候選模型參考 | 直接假設其語料可用 | 只作方向參考，不納入資料集 |
| 新聞全文、論壇、社群貼文、聊天紀錄 | 著作權與個資風險高 | 使用者本機明確匯入後的私有 adapter 訓練 | 公開 benchmark、可散布模型訓練 | 預設不使用 |

## Benchmark 路線

### Phase 0 公開 benchmark

優先資料：

1. 手寫合成句：由專案維護者撰寫，授權清楚。
2. 政府開放資料衍生詞彙：機關、地名、法規、行政詞。
3. 教育部 / 萌典讀音與詞彙：只作歧義詞與讀音種子，句子自行撰寫。
4. Taiwan.md 與國家文化記憶庫：只使用授權明確項目，並保留顯名與來源。

公開 benchmark 不應直接放：

- 新聞全文。
- 論壇貼文。
- 聊天紀錄。
- 使用者本機資料。
- 未確認授權的網站文字。

### Benchmark 類別

| 類別 | 建議來源 | 例子 |
|---|---|---|
| 同音歧義 | 教育部 / 萌典讀音與詞條 | 「在 / 再」、「做 / 作」、「台 / 臺」 |
| 台灣地名 | 政府開放資料、戶政 / 地政 / 觀光資料 | 行政區、道路、景點 |
| 機關與法規 | 政府開放資料、法規資料 | 部會名稱、法規名稱、常見行政詞 |
| 台灣生活用語 | 手寫合成、授權明確台灣知識資料 | 捷運、里長、健保、夜市 |
| 英文混輸 | 手寫合成、開發者訪談 | `GitHub Actions`、`Dockerfile`、`ETF` |
| 專業領域 | TMMLU+ 題目領域作參考，句子自行撰寫 | 醫療、法律、金融、科技 |

## Training 路線

### 可進公開訓練候選

條件：

1. 授權允許改作、訓練、散布衍生物。
2. manifest 記錄來源、授權、版本、抓取日期、處理方式。
3. 可排除個資與第三方敏感欄位。
4. 可切分 train / dev / test，且 test 不進訓練。

優先候選：

- 政府資料開放授權資料。
- CC0 資料。
- 明確 CC BY 且可改作資料。
- 專案手寫合成語料。

### 僅限本機 adapter 或研究

- 使用者明確選檔語料。
- 使用者明確開啟後的 L1 修正事件。
- 授權可本機使用但不可再散布的資料。

### 暫不納入訓練

- CC BY-ND 釋義全文。
- CC BY-SA 內容訓練可散布模型，除非先確認 share-alike 對模型權重與資料集的義務。
- 新聞、論壇、社群、聊天紀錄。
- 未確認授權的網頁抓取資料。

## 前處理規則

1. 保留來源 id 與授權欄位，不把來源資訊丟掉。
2. 分離 benchmark 與 training；benchmark 案例不得進訓練。
3. 所有句子需可轉成注音序列；缺讀音需記錄。
4. 台灣用語與泛繁中資料分開標記。
5. 英文片段需標記為 protected span。
6. 對教育部 / 萌典資料，只抽詞彙、讀音、歧義關係，不改寫釋義全文。
7. 對政府資料，保留顯名聲明與資料集版本。

## Phase 納入方式

| Phase | 動作 |
|---|---|
| Phase 0 | 建立 `corpus_manifest.json`，先做手寫 benchmark + 教育部讀音種子 + 政府開放詞彙 |
| Phase 1 | 用 benchmark 測 deterministic scorer，不新增 training |
| Phase 2 | 只從 manifest 中 `train_allowed=true` 的資料建立訓練集 |
| Phase 2.5 | L1 / L2 只做本機 adapter，不進公開 release |
| Phase 4 | Ubuntu 跑同一份 benchmark，確認跨平台一致 |

## 目前建議

1. Phase 0 先不要找大語料訓練模型；先用教育部 / 萌典找歧義詞，用政府開放資料找台灣命名實體，再手寫 50 到 200 句 benchmark。
2. Phase 2 若要訓練，優先使用政府開放授權、CC0、CC BY、手寫合成資料。
3. Taiwan.md 可作台灣詞彙發現與署名 benchmark 來源；模型訓練前先做 BY-SA 法務確認。
4. DRCD 可做泛繁中壓力測試，但不能代表台灣用語。
5. 使用者本機資料與修正事件只用於本機 adapter，不進公開模型。

## 2026-08-17 驗證語料（held-out，不覆寫上表）

完整調查：`docs/survey/2026-08-17_taiwan_validation_corpora.md`（外層 repo）。此節只記會改變下一步的結論。凍結的 `taiwan_ambiguous`、saturated 234、`heldout_generalization` 不再寫入新句子。

1. 完整 ASBC 4.0 需向計算語言學學會申請並付工本費（中文頁個人學術 NT$5,000；英文頁個人 US$200）。國網中心 2022/9 說明完整檔已因授權到期下架，只剩約 1 萬詞抽樣，且需 NCHC 帳號與點選同意。驗證主線不把付費 ASBC 當前置。
2. 不需使用者簽約即可取得、且適合作**新** held-out 的來源：手寫轉換句（MIT）、data.gov.tw 地名／站名／機關／路名／健保院所名（資料集 7442、7441、7438、73233、73226、7307、35321、168341）、全國法規法律與命令檔（18289、18290）、教育部辭典音讀種子（CC BY-ND 3.0 TW）、MozTW／Common Voice zh-TW 文本（CC0；Common Voice 26.0 卡片寫 21,766 句、其中 20,809 已驗證）、國教院已掛 OGDL 的學術名詞表。TMMLU+ 台灣科目只當詞覆蓋，不當第六源。
3. Wikipedia `zhwiki` 沒有官方「只含台灣」dump；條文是 CC BY-SA 4.0／GFDL。PTT 條款把未列名的第三方轉載定為侵權。自由時報著作權聲明要求事前書面授權。OSCAR 只對包裝與詮釋資料宣告 CC0，本文仍是 Common Crawl 原頁著作權。
4. 公開、句級、人工對齊的注音轉換集這次沒找到。讀音若之後自動產生，不得用受測的 `walk()`，也不得用簡體拼音函式庫再轉注音。
5. 台語 TAT、客語辭典不是國語注音驗證集。OpenCC `s2tw` 轉人民日報仍不是台灣用語驗證。
6. 下一步可做、且不必再問的工程：從第 2 點的 OGDL 名稱表抽出詞，手寫一組與凍結 fixture 不相交的覆蓋／轉換句。先不要下載 ASBC、新聞或論壇。
